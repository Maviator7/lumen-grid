# 都市のセーブ / v1

本編1枠。タイトルの「つづける」は、次回起動時にも保存した都市へ戻る。

## 保存タイミング
- 画面左下「都市を保存」、Cmd+S / Ctrl+S。
- 本編中30秒ごと（停止中も含む）。
- 都市生成・拡張・リセットの確定後、タイトルへ戻る前、ガイドへ切り替える前、フォーカス喪失・アプリの休止・終了。
- ガイドは保存しない。本編のセーブを保持し、ガイドからタイトルへ戻ると「保存した都市へ / L」で本編に戻せる。

## 保存内容
シード・生成器バージョン、全施設と拡張区画、配線と回線種別、ケーブル資材・専用回線・橋の枠、稼働時刻・通信統計・安定運転の秒数、直近の品質窓、移動中のパケット、送信待ち、処理クレジットを保存。カメラの回転・拡大・移動位置・視点、一時停止、速度、ツールも保存する。ただし都市の読込時は、保存時の運転状態にかかわらず一時停止で開く。戻す操作の履歴と一時的な選択・接続待ちは保存しない。

## 保存先と障害対策
Unity PlayerPrefsの `lumen-grid.city.v1` と `.backup`。JSON形式・形式バージョン・SHA-256チェックサムを検証する。書き込み前に候補を復元検証し、前回の有効な記録をバックアップに退避してから更新。主記録が不正ならバックアップを試す。両方読めなければ画面に通知し、元記録は削除しない。書込失敗時は少なくとも30秒あけて自動再試行する。ストレージ自体の故障に対して完全な保存保証はしない。

ブラウザ版は端末・ブラウザごとの保存。PlayerPrefsのWebGL総容量1MBに備えて主記録とバックアップを合わせ900KBまでに制限。サイトデータ削除・プライベートブラウズ・別端末では保持を保証しない。クラウド同期やファイルへのエクスポートは未実装。終了イベントに依存せず、稼働中の自動保存を行う。
