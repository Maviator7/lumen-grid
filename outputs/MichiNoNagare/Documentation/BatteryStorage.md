# 蓄電所（2026-11-11）

観測ツールで中継を選び「蓄電所に改装する」を押す。中継の位置・配線・通信機能を保ち、電力を蓄える設備を追加する。初期1枠、2回拡張するごとに1枠追加。撤去は残量を破棄することを二度目のボタンで確定し、設備枠を返す。別の中継へ選択を変えると確認を取り消す。回線Undoは設備を戻さない。

| 項目 | 値 |
|---|---|
| 容量 | 120 MJ |
| 充電上限 | 2 MW |
| 充電効率 | 90% |
| 放電上限 | 4 MW |
| 設置時残量 | 0 MJ |

1 MWを1秒使うと1 MJ。先に発電所から各地区へ供給し、不足分を蓄電所で補う。放電していない設備だけが発電所の余剰で充電する。蓄電所同士では充電しない。回線16 MWと中継の容量は充電・放電・通過電力の合計で共有し、その分だけ通信余力も減る。通信専用の回線では充放電できない。短い発電所経路が混雑する場合に、別の場所へ蓄えた電力を迂回して送ることもできる。

右の詳細で残量、充放電、住宅ピーク予告、中継負荷と通信余力、実際の供給元を表示。緑のラベル・金属セルと残量灯で区別する。停止中は充放電も停止し、表示流量は再開時の予定として示す。旧クラシック都市へ住宅ピークを後から追加せず、既存の不足時だけ補助する。

## 保存と計算

SavedBatteryの任意配列にノードIDと残量を保存。旧JSONの省略は0基として復元。非中継・重複ID・枠超過・非有限または0〜120以外の残量を拒否する。ライブ状態は公開読み取り専用、保存DTOは独立コピー。残量の増減は正のシミュレーションステップだけで行い、編集・ロード・停止・候補表示では積分しない。0秒のプレビューで保存された品質・安定時間を変えない。正のステップで供給不足になったら安定時間を即座に解除する。

BatteryStorageが充放電と独立した電力収支を所有する。充電の流れはPowerFlowsの地区供給記録と分離し、設備の電力診断には両方を合算する。BatteryPowerCacheは需要・供給・中継容量・ノード種別・配線・残量・刻み幅が変わらず、満杯/空の境界を跨がないときだけ流量を再利用する。充電中に地区の不足または他設備の放電があれば再配分し、新たに貯まった電力の使い道を再検討する。
