# インフラ設備の金属表現（2026-11-04）

対象は発電所、データセンター、中継ハブ。住宅・背景ビルは従来の外装を維持。

- ガンメタルの本体と黒いガスケット、銀色のカバー・レール・アンカーボルト。
- 発電所は共有トーラスメッシュの銅製巻線と細い発光帯。
- Standardマテリアルの金属度と滑らかさを使い分け、128pxの細い研磨模様を生成。
- 64px×6面の静的な夜景環境マップと弱いリムライトで、視点に応じたハイライトを出す。毎フレームの反射プローブ撮影は行わない。
- 発電所・データセンターの既存ポイントライトは負荷とシミュレーション時刻でわずかに変化し、近くの金属面も照らす。
- 動的素材はownedで追跡。再構築時にテクスチャ・環境マップ・共有メッシュ・キャッシュを破棄し、以前のRenderSettings反射設定を復元。
- 旧都市にも表示される。供給計算、セーブ形式、シードは変更しない。

Unity 6000.3の反射設定の保存・復元はTexture型のcustomReflectionTextureを使う。Cubemap専用の旧getterは初期設定の種類によって例外を出すため使わない。

## 確認

Web・Macビルド成功（ビルド内の既存コア検証成功）。別ポート8768で施設の外観、拡大と視点回転、拡張による描画再構築、再起動を確認。修正済みビルドを新規タブで開いた際のWebコンソールエラーなし。検証したファイルと公開先の全ファイルのSHA-256一致を確認。ユーザーのChrome8766の都市は操作していない。
