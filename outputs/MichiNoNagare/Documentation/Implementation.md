# Unityへの最初の移植

承認済みのブラウザ版を、Unityの独立プロジェクトへ移す。
- 純粋なC#コア: 道路・通行制限・車種・衝突回避・経路・60秒の目標判定。
- Runtime: プリミティブの3Dジオラマ、マウスの道路編集、カメラ、HUD。
- Editor: 検証コマンド、起動シーンの生成、Macアプリ出力。

最初のスコープは固定マップ1面。道路56マス、橋2本、専用タイル6枚。
乗用車は住宅→オフィス。大型トラックは工場→倉庫、貨物6個を運ぶ。
未整理の初期配置は60秒目標を未達。近道の橋を通勤専用にすると、物流が下側の橋を使い目標達成。
都市成長、音声、復路、アセット制作は後続。

確認: コアの通行制限、予算、取り消し、目的地への経路、達成判定、車体の間隔を実行して検証し、Unityでコンパイル・シーン生成・Macビルドまで行う。
