# タイトル画面

起動時はロゴ・夜の都市・データの流れを表示する。初回背景は使い捨ての解法例で、本編の新規開始は選択したシードの初期配線から始まる。

- 新しい都市（N / 初回Enter）：シード選択。生成の確定で既存都市と拡張を置換。キャンセルで保持。
- つづける（Enter / Esc）：保存した本編の都市、または今回の起動中の都市へ戻る。配線、拡張、時刻、カメラ、ガイド段階、同じ起動中の一時停止状態を保持。起動時にセーブから読込む場合は必ず一時停止。
- 操作ガイド（H）：既存都市がある場合は置換の確認を表示。
- 本編の左下ボタン / M：タイトルへ。既存都市の時間を止め、接続待ち・ドラッグ・開いているダイアログを解除。
- 本編は終了後もセーブから再開可能。詳細はSaveSystem.md。操作ガイドは保存対象外。
