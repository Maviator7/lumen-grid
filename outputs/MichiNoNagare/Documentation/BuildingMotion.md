# 控えめな建物アニメーション（2026-11-04）

- 発電所：出力負荷に応じ、3本のコイルが少しずれた位相で明滅。振幅は最大9%。
- データセンター：既存の18灯を使い、送信中に列ごとの光がゆっくり流れる。通信量に連動し、未稼働時は暗く一定。
- 工業区：煙突の稼働灯と、中央の煙突から上がって薄く消える2個の小さな蒸気。未供給時は蒸気の発光がゼロになる。
- 住宅：窓明かりを最大4.5%だけ緩やかに変化。建物ごとに位相をずらす。
- 医療区：サインは最大4.5%の変化に抑え、電力供給に応じて暗くなる。強い点滅は避ける。

描画だけの変更で、旧都市・新都市の両方に適用。供給計算・シード・セーブ形式は変更しない。

NetworkBuildingMotionはsim.Timeから絶対値で光量と位置を算出。一時停止や既存都市のタイトル表示中は進まない。リストと素材は建設時に登録し、Sync時は値の更新のみ。工業区に追加するオブジェクトは2個。素材は既存のowned管理に登録し、DisposeSceneで参照リストも破棄する。
