# 4方向の地区開放（2026-11-11）

北・南・東・西の4方向から開放先を選ぶ。開放前に方向、地形図、需要、通信期限、追加資材・専用枠・川越え枠、供給施設の有無を表示する。45秒の安定条件は変えず、どこへ進むかをプレイヤーが選ぶ。

## 地形

- 河岸地区（北・南）: 従来の川の両岸へ伸びる地区。川越え枠と中央の経路が重要。
- 密集地区（東西）: 建設できない範囲が2か所あり、その間の通路に中継を置ける。直結の通信経路は障害物で塞がれる。
- 迂回地区（東西）: 大きな建設不可範囲の外側へ回線を回す。距離と中継負荷を考える。

東西の2候補には異なる地形が出る。種類はシード・拡張回数で再現する。建設不可範囲は見た目だけではなく、見積もり・確定・参照解・保存復元で同じ判定を使う。合法な別経路を設計する自由は残す。

## 生成と安全性

東西は既存施設・障害物の外縁より外側へ追加する。既存の建物や追加する中継の台座を避けて進入路を計画し、長い区間は11.5以内へ分割する。新しい建物の正方向への張り出しも考慮し、地区と障害物を離す。既存のノードを動かさず、既存の回線へ新しい障害物を被せない。

候補はクローン上で合法な参照配線と実際の運転を検証してから開放可能になる。候補表示で本編を変更しない。進入路や供給を確保できない場合は、その方向を選べない理由を表示する。

## 保存互換

初期マップのGeneratorVersionと地区別RulesVersionは変更しない。従来の北・南の配置・資材条件は維持する。既に開放した地区は生成し直さない。

保存には任意の方向・地形・障害物・地区までの中継経路を追加する。旧JSONで方向が省略されていれば、元のNorthフラグから北または南を復元する。旧地区には新しい障害物を後から追加しない。新しい経路は連続性・ノード種別・重複・距離・障害物を検証する。
