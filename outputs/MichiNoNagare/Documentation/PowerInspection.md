# 送電量0と実際の供給元の説明（2026-11-08）

## 表示

- 中継の「送電の占有」を「通過電力 … MW」に変更。
- 通過量が正の場合、その中継を実際に通過する発電所別の電力量を表示。
- 0 MWで発電所にも需要地区にも経路があり、接続先の区画が充足していれば「接続済み・現在送電なし」「接続先の区画は別経路から供給中」を表示。ここに挙げる供給元は接続先区画に届いた実配分で、その中継を通過したものではないことを見出しで区別。
- 発電所への経路なし、需要地区への経路なし、接続先の電力不足は別の説明にする。
- 発電所の詳細は発電容量・現在の供給・未使用容量と待機理由を表示。
- 需要地区の詳細は、その地区に実際に届いた電力の供給元を表示。0 MWの地区に隣接地区の供給元を混ぜない。
- 供給元は上位2か所と残りの件数を表示し、詳細パネルの長さを抑える。
- 回線の詳細にも、0 MWの意味と通信専用には電力が流れないことを記載。
- 操作ガイド4・13に、需要量に応じて流れること、近い経路を優先すること、接続済みでも通過0になることを追記。

## 計算

AllocatePowerの配分順序・距離の評価・容量判定は変更しない。既に決定した正の配分をPowerFlowに記録し、選択施設の診断をキャッシュする。再配分時に記録とキャッシュを破棄する。セーブは派生記録を保存せず、ロード時の既存の再配分で再構築する。セーブ形式変更なし。
