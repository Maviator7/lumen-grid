# 滑らかな回転 / 2026-10-30

Q/EのGetKeyDownで20度飛ばす処理を廃止し、押している間80度/実時間秒で回転する方式へ変更。動き始めと停止は応答時間0.1秒の指数追従で滑らかにする。両方押すと入力は相殺。画面の左右回転ボタンは20度の目標を追加して補間する。

OrbitRotationは移動目標に対する追従を解析積分し、30fpsと144fpsで同じ時間入力した際の角度差を抑える。ゲームの一時停止・1/2/4倍速と独立。0.1秒以上のフレーム停止ではゲーム入力側でdtを抑え、復帰時の急なジャンプを防ぐ。

タイトル・各確認画面・フォーカス喪失中の回転は停止。ロード、初期位置、都市全体、拡張時のカメラ再構築は残った目標を破棄。保存する角度は現在見えている角度で、保留回転は保存しない。
