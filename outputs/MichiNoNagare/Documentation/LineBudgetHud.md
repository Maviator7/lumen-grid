# 回線本数と資材の表示（2026-11-02）

本数と距離を別の制限として表示する。計算ルールは変更しない。

- 全回線長：共用・送電専用・通信専用の長さをすべて合算。
- 共用：現在の本数を表示。本数そのものの上限はない。長さと川越えの枠は使う。
- 送電専用／通信専用：それぞれの現在本数を同じ行で表示。
- 専用枠：送電専用＋通信専用の合算使用数／上限と残り本数を表示。
- 川越え：種類にかかわらず川を横切る回線が1本につき1枠を使う。
- 同じ回線の専用種別を変えても専用枠は増えない。共用へ戻すと1枠回収。
- 都市拡張で専用枠+2、川越え+1。回線長は拡張候補の支給量に従う。

フッターを192基準ピクセルに拡げ、資材の行と保存ボタンの間隔を確保。入力除外と施設ラベルの安全領域も同じFooterHeightに合わせる。
