# 開始時の一時停止
新規都市を生成した際と、本編セーブをロードした際は必ずPaused=true。保存時に運転中でも自動再開しない。右上「都市を再開」、Space、Enterで明示して開始する。同じ起動中にタイトルへ戻ってつづける場合は、これまで通りその時点の停止/運転状態を保持。

検証: WebGLとMacビルド成功、ビルド内の既存検証PASS。利用中の8766とは別の8767オリジンで実機確認。新規開始でCITY PAUSED、送信待ち/移動中0、しばらく後のタイトルでも稼働0秒。Spaceで運転開始し稼働44秒で保存。リロード後につづけるをクリックしてCITY PAUSED。待機してもタイトルの稼働44秒のまま。ブラウザerrorなし。検証タブと8767サーバーを終了。
