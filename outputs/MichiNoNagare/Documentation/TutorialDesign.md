# Guided first connection

Start the native game in a skippable, interactive tutorial. Begin with the reactor-to-west relay cable absent, showing 0% electricity. The player selects power, clicks the reactor then R.01, and immediately sees power reach all districts without an extra switch. Explain that existing shared cables carry it onward automatically. Next inspect the central hub, add a R.01–R.03 power bypass, convert R.01–NEXUS to data-only, and run the existing 45-second test. Progress follows actual graph and selection state, never a timed sequence. Wrong targets provide a specific hint and do not change the graph. All tool actions, keyboard shortcuts and preset actions use the same gate. Preserve pan/rotate/zoom and provide camera reset; changing camera must not hide guidance targets.

Use a compact left guide (one instruction per step, numbered progress, skip), contextual pulsing target markers, highlighted next tool/launch and a preview route. Persistent Japanese role labels distinguish power source, data source, relays and districts; skyline is explicitly decorative. Provide plain-language inspector descriptions. H/top help replays; restarting deliberately resets the current layout. Skip retains the current network for free play. Completing the lesson keeps the solved network and offers free play.

Validation: pure-state full lesson, incorrect input gate, electricity 0→100, bypass solution pass, retry/restart/skip. Native layout/startup/keyboard QA, compilation and regression checks. Native automation mouse coordinates are known unreliable: do not claim human mouse verification without observing success.

Review resolution: Undo, presets and removal are disabled during the lesson with explanations. Escape/drag cancels a pending endpoint and returns to its source step. Skip ends the lesson while preserving the current layout; there is no implicit continue action. H opens an explicit replay/reset prompt with Cancel, so no layout is erased on a help keypress. The next lesson starts only after the reset button. Test failure returns to the launch stage, where redesign/retry is available. The lesson's final graph uses all three dedicated lines and is verified by TutorialChecks.
