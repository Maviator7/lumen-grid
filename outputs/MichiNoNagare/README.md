# LUMEN / GRID — 都市の循環を設計する

Unity 6000.3.11f1。夜の都市に電力とデータを届けるネットワーク・パズル。同じ都市を広げ続ける本編と、固定操作ガイドを遊べます。

## 遊ぶ
今回のロゴ反映版は、隣の `LumenGrid-Branded-Mac/LumenGrid.app` を起動します。バランス調整も含まれます。旧版の起動中プレイを残すため別フォルダにあります。通常のビルド先は `LumenGrid-Mac/LumenGrid.app` です。
Unityで開く場合は `Assets/Michi/Scenes/Nocturne.unity` を開いてPlay。
ジオラマ・回線・HUDは実行時に生成されます。

## シード都市で遊ぶ
起動するとシード291026の本編都市を開きます。上部の「都市を生成」またはGでシード入力を開き、整数を入力して生成。Enterでも生成できます。同じシードは同じ施設配置・需要・川・建設不可エリア・建物を再現します（生成器v1）。「ランダム」で別のシードを選べます。生成すると現在の配線をリセットし、キャンセルなら保持します。ダイアログを開いている間は都市の時間が止まります。

川を横切る回線は橋を1枠消費（初期上限3、拡張ごとに+1）。撤去で枠が戻ります。橙色で囲まれた建設不可エリアを横切る接続はできません。回線長の予算は都市ごとに変わり、左下に表示します。区画の位置と電力需要も変わります。工業区は工場・煙突・タンク、居住区は集合住宅、医療区は十字マークとヘリポートのあるキャンパスです。

「配線リセット」ボタン / F1は確認画面を開きます。「リセットする」を押すと同じシードの最初の地区と配線に戻り、拡張した地区・編集・稼働記録を消去します。Esc / Enterはキャンセル、⌘ / Ctrl + Enterは確定。確認中は検証を一時停止し、キャンセルで再開します。

F2は開放済み地区全体の解法例、F3は配線を白紙にします。シード自体の表示は上部にあります。

## はじめて遊ぶ
上部の「操作ガイド」またはHで、固定マップの練習を開けます。配置リセットの案内が出るので、始めるかキャンセルを選びます。光るツールと接続点を順番にクリックしてください。一本つながると電力供給が0%から100%に変わります。その後、中央ハブの混雑を専用線で解消します。

「ガイド終了」は配置を保って自由操作へ切り替えます。練習中は誤操作を防ぐため、指示された接続だけ有効で、Undo・撤去・F1〜F3は使いません。Escやドラッグで接続をキャンセルしても、接続元の案内に戻れます。ガイド終了時の「新しい都市へ」でシード生成を開けます。

施設には日本語名と役割を表示。オレンジは電力、青い光は移動するデータです。奥の高層ビルは背景用です。

## 本編：同じ都市を広げ続ける
本編は自動で運転を始め、45秒経っても終了しません。停止中・運転中どちらでも配線を接続・塗り替え・撤去・Undoできます。配線の編集や地区の開放で、既存の街・配線・稼働時間・配送実績を保持します。

全地区に電力98%以上、直近15秒の通信成功率90%以上・平均遅延2.8秒以内で供給し、45秒連続で安定すると拡張が解禁されます。Xまたは左の「隣接地区を開放」で北・南から選択。区画の種類と需要、追加資材を確認して開放します。開放を待って今の街を調整し続けることもできます。

新しい需要区画・中継施設が増え、既存の同じ岸の回線が延長されます。川を渡る回線と区画への接続は自分で作ります。発電所・データセンターが追加された場合も接続が必要です。回線長は延長分+36、専用回線は+2本、橋は+1枠。新しい需要を満たすまで安定時間は進みません。再び45秒安定させると次の拡張へ進めます。

## 通信の需要とセンターの出力
本編の通信需要は工業区2件/s・居住区1.5件/s・医療区3件/sです。最初の3地区は合計6.5件/sで、データセンター1基（7件/s）で賄えます。拡張すると通信需要も増えるため、追加センターをつなぎ、混雑しない経路で供給を分担する必要が出てきます。全施設の接続を一律に必須にはしません。既存設備で賄える間は使い続けられます。

要求は需要に応じて生成され、センターの出力が足りなければ「送信待ち」になります。生成から5秒以内に届かなかった要求は失敗です。送信待ち時間も期限と遅延に含みます。近いセンターが上限なら、別の到達可能なセンターも使います。センターの出力とは別に、回線・ハブの共用処理枠にも制限があります。

左の「通信需要」「接続出力」「未接続」「送信待ち」で不足を確認できます。接続出力は少なくとも1地区へ届けられるセンターの合計上限で、経路上の混雑まで保証する数値ではありません。センターを観測すると上限と実際の送信量、地区を観測すると需要と受信量を表示します。

通信成功率は、直近15秒に結果が確定した要求の「成功 /（成功＋失敗）」です。送信待ち・移動中はまだ未確定で、元の期限に達すると失敗へ計上します。移動中を即座に失敗とは扱いません。チュートリアルの需要・45秒判定は従来通りです。

## 供給の仕組み
発電施設とデータコアから、工業区・居住区・医療区へ供給します。
電力は連続した供給量、データは移動・待機・期限切れのあるパケットです。
共用ハブは電力の中継で処理枠を使い、残りの枠でデータを処理します。
これは架空の共用インフラのゲームルールです。実際の送電網の物理計算とは異なります。

- 回線長は左下の予算内（練習は78）。接続1本は11.5以内。
- 共用・送電専用・通信専用。専用回線は初期合計3本、拡張ごとに+2本。
- 本編は45秒の連続安定で拡張を解禁。練習だけは45秒テストでクリア判定します。
- 全区画が通信を利用するには十分な電力が必要です。データの有効期限は5秒。

## UI
HUDは画面サイズに合わせて一括拡大し、Retina・大きいウィンドウでも文字と操作対象を同じ比率で保ちます。上部に供給計器、下部中央に回線ツール、左右に資材とカメラ操作を配置。切り欠きフレームと専用アイコンで選択状態を表示します。

## 操作
- 左ボタンを押したままドラッグでマップ移動。短いクリックはノード・回線操作（ボタンを離した時に確定）。UI上からのドラッグは移動しません。
- 1 共用 / 2 送電専用 / 3 通信専用 / 4 撤去 / 5 観測。
- ノード→ノードとクリックして接続。回線をクリックすると選択中の種類へ塗り替え。
- 撤去モードで回線をクリックすると回収。Cmd/Ctrl+Zで取り消し。
- 観測でノードを選ぶと、負荷と通信余力を表示。
- 本編はEnter / Spaceで停止・再開。練習はEnterで45秒の検証を開始。
- Spaceで停止・再開、Tabで1×/2×/4×。
- Xで拡張、1 北 / 2 南で確定、Escで閉じる。
- F1 初期状態への確認、F2 解法の一例、F3 白紙（練習中は無効）。
- Q/Eでカメラ回転、ホイールでズーム、画面右下で真上視点・都市全体を表示（Vでも全体表示）。
- Escで接続元・選択を解除。

## ロゴとアイコン
電力の琥珀色と通信のシアンで「L / G」を組んだ、角を切った二本の回線のマークです。ゲーム内上部は透過ロゴ、Macアプリは同じマークのアイコンを使用します。

`Assets/Michi/BrandingSource` に編集できるSVG、`Resources/Branding` にUnity用PNGがあります。配布用のSVG・PNGとデザイン一覧は隣の `LumenGrid-Branding` フォルダに保存しています。文字もベクターパスで作成し、外部フォントに依存しません。ビルド処理が透過設定とアプリアイコンを設定します。

## 開発・検証
- `Tools/check-core.sh`: 旧交通コアと新ネットワークコアを、Unity起動なしでコンパイルして検証。
- `Tools/build-mac.sh`: コア検証・Nocturneシーン生成・Macアプリのビルド（エディターを閉じて実行）。
- Unityの `Michi` メニューからも実行できます。
- 起動中の旧アプリを残して別名のビルドを作る場合は、環境変数 `MICHI_MAC_BUILD_PATH` に出力する `.app` の絶対パスを指定できます。
- 別のUnity.appを使う場合は `UNITY_EDITOR_APP` を指定します。

`Core/NetworkSimulation.cs` はUnity非依存の計算、`Runtime/Network*` が表示・入力・HUD、`CityBloom` は軽量の発光表現です。
日本語フォント、描画用シェーダー・マテリアルをプロジェクトに含めています。
旧版の `Riverside.unity` と交通コード、旧Macアプリは比較用に残しています。

本編は10施設・3区画から始まり、北・南へ地区を追加する初期の成長モードです。自由なハブ配置、音声、保存、製品向け最終アセットは後続です。現在は終了すると都市の進行は保存されません。
Gitは未初期化です。開発ルールはAGENTS.md / CLAUDE.mdにあり、構成変更時に更新します。
