# 通信ピークとセンター増強

ユーザー承認済み：予告付き通信ピークとセンター増強をセットで追加。既存都市では任意有効化し、配線と都市を維持する。

通信ピークは有効化から90秒後に始まり、120秒周期の最後30秒。有効化から90秒の準備猶予を取る。住宅1.5→3件/s、工業2→3件/s、医療3件/sは一定。既存の通信期限・電力ピーク・RulesVersion・地形生成器は変更しない。新規都市は有効、旧保存の省略は無効。設定から説明を読んで有効/無効を選べる。停止・設定画面中は時刻が進まない。

センターを観測して7→11件/sへ増強できる。増強枠は初期1、2回拡張ごと+1。増強には追加電力2MWが必要で、出力は7+4×追加設備への電力供給率。送電できなければ追加分が働かず基本7件/sに戻る。標準へ戻すと追加電力をやめて枠を返却する。増強操作は配線や移動中パケットを巻き戻さない。ピーク無効でも増強は利用でき、その電力負担は残る。

増強センターは電力の需要施設として、通常の経路・回線16MW・中継容量・蓄電所の制約で供給する。供給率、電力不足の警告、45秒安定判定に追加設備の電力も含める。地区の電力不足数と増強センターの不足数は区別する。電力診断は選んだ需要施設への実配分を示す。

Core/CommunicationPeaksが任意設定・時刻・需要・増強設備を所有。保存は任意のフラグ/起点時刻/増強センターID配列。旧JSONは変更なし。範囲・有限の起点時刻・ID種別・重複・枠数を検証。クローンと保存で設備リストを共有しない。初期化は増強を撤去し、ピークの選択は維持して準備時間をリセット。候補の参照解はピーク最大需要に必要な増強と合法な蓄電を含め、実運転で確認してから開放可能にする。

UIは左の通信需要/ピーク需要、接続実効出力、次の通信ピーク時刻、設定への導線を明示。センター詳細は実効/最大出力、送信量、追加電力の供給率と供給元、枠と増強/標準ボタンを画面内へ収める。設定ダイアログは既存の入力・回転・計算・操作を遮断する。増強したセンターは既存の金属サーバーに追加セルとアクセントを付け、シーン所有の描画物を回収する。

検証：有効化の猶予/境界/繰り返し、旧需要の不変、増強出力と電力の物理的配分、供給不足での能力低下、蓄電との協調、切替/編集/ロードで残量や時刻を進めない、旧・新JSON、クローンの独立性、複数シードと4方向拡張。別ポート8769で実画面・保存/リロード・設定のキャンセル・1280x720の見切れを確認。本編8766へテストデータを書かず、サーバーを再起動せずに検証済みWebを差し替える。
