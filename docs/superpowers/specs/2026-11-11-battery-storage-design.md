# 蓄電所の追加

ユーザー承認済み: 余剰電力で充電し、需要ピークで放電する蓄電所。容量・出力・設置場所に制約があり、残量と状態、次の住宅ピークを表示する。

中継を選んで蓄電設備に改装する。中継の通信・送電機能と位置、配線は維持。最初に1枠、2回拡張ごとに1枠追加。設置直後は空。120 MJ、充電最大2 MW、充電効率90%、放電最大4 MW。1 MW = 1 MJ/秒。通常の発電を先に地区へ配り、不足だけを蓄電所から補う。放電しなかった蓄電所は発電所の余剰を使って充電し、蓄電所同士で充放電しない。回線16 MWと中継処理容量を充放電にも適用する。空なら放電不可、満杯なら充電不可。同一ステップで充放電しない。配線編集・停止・ロードで残量を増減しない。

改装可能な中継の詳細に設備の説明、空き枠、改装ボタン。設置済みなら残量/容量と割合、充電・放電レート、状態（満充電、空、経路なし、余剰待ち等）、ピーク予告を表示。撤去は二段階確認し残量を破棄、枠を返却。配線のUndoは設備を変更しないことを操作説明に明記。全体パネルにも設備枠・残量と「中継を観測して改装」の導線。専用の薄緑のラベル・小型セル模型とシミュレーション時刻に同期する灯りを追加。

旧セーブは設備0として読み込み、既存ルール・既存施設・配線・需要を変更しない。クラシックでも供給不足時の補助として使用可、住宅ピークは追加しない。保存に任意の蓄電状態配列を追加し、ノードID・重複・枠数・有限の残量0〜120を検証。設備設定・残量はクローンとスナップショットで独立させる。

検証: 充電エネルギー収支、地区優先、有限放電、充電効率、満杯・空・断線・通信専用・回線/中継制限、複数設備、既存ルールと保存再開の一致、旧JSON、拒否される不正データ。別ポートの画面で改装・充電・放電・撤去確認とリロードを確認。本編Chrome8766のセーブを操作せず別出力から公開。

配分単位の放電率カウンタは中継の通過負荷と分離する。合計放電は残量/dt、合計充電入力は空き容量/(0.9×dt)でも制限し、複数経路で残量を二重利用しない。dt=0は1/60秒相当の可否・流量を表示するだけで残量を変更しない。
